# Showcase

This folder contains public showcase assets for the open-source repository:
mobile UI screenshots, sample recognition workflow images, and the current app
icon.

These files are for documentation and result display only. They do not include
pretrained model weights, training data, calibration data, private deployment
credentials, or production uploads.

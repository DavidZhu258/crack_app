# App 功能验证与实机测试指南

## 1. 本地代码验证

在 `E:\FlutterProject\crack_app` 执行：

```powershell
flutter analyze
flutter test
```

通过标准：
- `flutter analyze` 显示 `No issues found!`
- `flutter test` 显示 `All tests passed!`

## 2. 连接 Android 真机

1. 手机打开开发者选项和 USB 调试。
2. 用 USB 连接电脑，手机上允许调试授权。
3. 在项目目录执行：

```powershell
flutter doctor -v
flutter devices
```

确认设备出现在列表中后运行：

```powershell
flutter run -d <deviceId>
```

性能验证建议使用 profile 或 release：

```powershell
flutter run --profile -d <deviceId>
flutter build apk --release
```

如需查看运行日志：

```powershell
flutter logs -d <deviceId>
```

## 3. 离线场景验证

矿洞无网络时重点验证离线可用性：

1. 手机开启飞行模式，并关闭 Wi-Fi。
2. 启动 App。
3. 进入裂隙检测页面。
4. 使用测试图片、相册图片或拍照图片执行检测。
5. 检查结果页是否显示裂隙覆盖图、裂隙占比、检测耗时、检测数量。
6. 进入 JCI 检测流程，填写岩性、埋深、渗水等工程信息。
7. 检查 JCI 值、围岩等级、支护建议和历史记录是否生成。
8. 关闭 App 后重新打开，确认历史记录仍可查看。

通过标准：
- 无网络时不要求登录也能完成检测。
- 检测失败时页面不崩溃，并能继续重新选择图片。
- 历史记录显示本地或待上传状态。

## 4. 在线场景验证

在线推理需要服务器实现 `docs/api/online-offline-mvp-api.md` 中的接口。

如果服务器在电脑上运行，手机不能访问 `127.0.0.1`，需要：

1. 服务器监听 `0.0.0.0:8000`。
2. 用 `ipconfig` 查看电脑局域网 IPv4 地址。
3. 手机和电脑连接同一网络。
4. App 登录窗口中填写 `http://<电脑IPv4>:8000`。
5. Windows 防火墙允许该端口访问。

在线验证流程：

1. 手机联网。
2. 打开登录入口，填写服务器地址、用户名、密码。
3. 登录成功后执行裂隙检测。
4. 确认服务器可达时优先使用服务器推理。
5. 断开服务器或关闭网络后重新检测，确认 App 回退到离线推理。
6. 重新联网后检查待同步记录是否可以上传，并获得云端记录 ID。

通过标准：
- 服务器可用时可登录和推理。
- 服务器不可用时 App 不阻塞离线检测。
- 待同步记录不会丢失。

## 5. 权限与异常验证

至少验证以下异常路径：

- 首次启动拒绝相机权限，再重新进入拍照。
- 首次启动拒绝相册权限，再重新选择图片。
- 选择超大图片，观察是否能压缩并完成检测。
- 输入非法埋深、缺少岩性、缺少渗水状态，检查表单拦截。
- 检测过程中切换前后台，返回后检查页面状态。
- 连续执行 3 次检测，确认内存没有明显异常增长或闪退。
